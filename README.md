# Landing page Perksverse

Página publicada: https://perksverse-landing.jpjs.chatgpt.site

Página estática em português no repositório próprio `perksverse/perksverse-landing`. Abra `site/index.html` para uma inspeção rápida ou sirva a pasta `site/` por HTTP para testar a navegação e o formulário.

## O que está pronto

- Apresentação da proposta do Personal Benefits Hub, fluxo de uso e limite de elegibilidade.
- Identidade visual SVG do repositório `perksverse-docs`.
- Prévia ilustrativa da interface, rotulada como exemplo.
- Pesquisa curta com validação, preparação e cópia das respostas.
- Layout responsivo e navegação por teclado.

## Antes de publicar

1. Definir o destino autorizado para receber respostas da pesquisa e integrar esse destino. A versão atual não envia nem armazena respostas; ela deixa o visitante copiá-las.
2. Confirmar redes sociais oficiais e trocar os rótulos “em breve” por links reais.
3. Confirmar se haverá vídeo oficial. A prévia visual atual é uma ilustração em HTML/CSS, não uma gravação do produto.
4. Confirmar URL de produção, política de privacidade e domínio antes de abrir coleta de dados pessoais.

Não há dependências de build. Este repositório continua privado; apenas a página hospedada no Sites está pública. O plano atual da organização não permite GitHub Pages para este repositório privado. Para atualizar a página publicada, sincronize os arquivos de `site/` com a origem do Site e publique uma nova versão. Os caminhos dos assets são relativos.

Conteúdo baseado no README, visão do produto, requisitos e assets de marca do repositório `perksverse-docs` consultados em 23/10/2026. O site comunica uma proposta em desenvolvimento e não anuncia ofertas reais nem disponibilidade do produto.
